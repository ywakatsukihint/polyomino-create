# Polyomino木数計算

## 概要

このプログラムは、  
**頂点数 n を入力として、最大次数が 4 以下であるラベル無し・根なし木**
（unlabeled unrooted trees）の

- 個数の計算
- 各木の列挙
- 隣接リストおよび隣接行列の出力

を行います。

木の同型判定には **AHU アルゴリズム（正規形）** を用いており、
重複なく正確に列挙されます。

---

## 特徴

- ラベル無し・根なし木を正確にカウント
- 最大次数 ≤ 4 の制約を厳密に満たす
- 各木について以下を出力
  - 正規形（canonical form）
  - 隣接リスト
  - 隣接行列
- C++11 対応
- 研究・学習用途向けの明快な実装

---

## 実行環境

- C++11 以上
- 推奨コンパイラ：g++（MinGW / WSL / Linux / macOS）

---

## コンパイル・実行方法

```bash
g++ trees_deg4.cpp -std=gnu++11 -O2 -o trees
./trees
````

実行後、頂点数 `n` を入力してください。

※ 全列挙のため、`n ≤ 16` 程度が現実的な上限です。

---

## 出力例（概要）

* 条件を満たす木の総数
* 各木の canonical 表現
* 隣接リスト（0-indexed）
* 隣接行列（n × n）

---

## アルゴリズム概要

1. 最大次数制約を満たす根付き木を動的計画法で生成
2. 根付き木を無根化し、中心（1点または2点）から正規形を計算
3. 正規形による同型判定で重複を除去
4. ラベル無し・根なし木として列挙・カウント

---

## 注意

* 本プログラムは **全列挙アルゴリズム** を用いています。
* 頂点数が大きくなると計算量は急激に増加します。
* 高速化が必要な場合は Redelmeier 法や McKay の生成法への拡張が考えられます。

# polyomino.cpp

## 概要

このプログラムは、指定した正整数 `N` に対して

- サイズ `N` の **すべての異なるポリオミノ（Polyomino）** を生成し  
- 回転・反転を同一視した **同型判定** を行い  
- 各ポリオミノについて  
  - 形状の可視化（`#` と `.`）
  - 市松模様による 2 彩色に基づく **二部グラフの隣接行列**

を出力する C++ プログラムです。

---

## 機能

- DFS によるポリオミノ全探索
- 正規化と 8 通りの回転・反転による同型除去
- 市松模様による二部グラフ化
- 隣接行列の生成と表示
- 全ポリオミノ数 `|P_n|` の出力

---

## 使い方

### コンパイル

```bash
g++ -std=c++17 main.cpp -O2
````

### 実行

```bash
./a.out
```

実行後、標準入力で `N` を入力してください。

---

## 出力例

* 各ポリオミノの形状（`#` がマス）
* 対応する二部グラフの隣接行列
* 最後に生成されたポリオミノの総数
