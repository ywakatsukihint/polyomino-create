#nオミノ生成.js

##概要

正方形の数を固定した Polyomino を生成する JavaScript のプログラムです．
一部，ChatGPT補助

##入出力

正方形の個数を表す数を入力すると，その個数の正方形を持った Polyomino を表として出力します．
0は正方形のない部分，1以上の数は，その位置に正方形を配置することを意味しており，それぞれの数字は，その位置にある正方形に接している正方形の数を表しています．

#Polyomino木数計算.cpp

## 概要

このプログラムは、  
**頂点数 n を入力として、最大次数が 4 以下であるラベル無し・根なし木**
（unlabeled unrooted trees）の

- 個数の計算
- 各木の列挙
- 隣接リストおよび隣接行列の出力

を行います。

木の同型判定には **AHU アルゴリズム（正規形）** を用いており、
重複なく正確に列挙されます。

---

## 特徴

- ラベル無し・根なし木を正確にカウント
- 最大次数 ≤ 4 の制約を厳密に満たす
- 各木について以下を出力
  - 正規形（canonical form）
  - 隣接リスト
  - 隣接行列
- C++11 対応
- 研究・学習用途向けの明快な実装

---

## 実行環境

- C++11 以上
- 推奨コンパイラ：g++（MinGW / WSL / Linux / macOS）

---

## コンパイル・実行方法

```bash
g++ trees_deg4.cpp -std=gnu++11 -O2 -o trees
./trees
````

実行後、頂点数 `n` を入力してください。

※ 全列挙のため、`n ≤ 16` 程度が現実的な上限です。

---

## 出力例（概要）

* 条件を満たす木の総数
* 各木の canonical 表現
* 隣接リスト（0-indexed）
* 隣接行列（n × n）

---

## アルゴリズム概要

1. 最大次数制約を満たす根付き木を動的計画法で生成
2. 根付き木を無根化し、中心（1点または2点）から正規形を計算
3. 正規形による同型判定で重複を除去
4. ラベル無し・根なし木として列挙・カウント

---

## 注意

* 本プログラムは **全列挙アルゴリズム** を用いています。
* 頂点数が大きくなると計算量は急激に増加します。
* 高速化が必要な場合は Redelmeier 法や McKay の生成法への拡張が考えられます。
